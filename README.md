# NeuralFin Site

Standalone Next.js landing page for NeuralFin.

## Routes

- `/` - English homepage
- `/zh` - Chinese homepage
- `/api/health` - deployment health check

## Development

```bash
npm install
npm run dev
```

The local dev server runs at `http://localhost:4182`.

## Build

```bash
npm run build
```

## Assets

Brand, partner, app-store, and product screenshot assets live in `public/assets`.

This project is intentionally separate from the Bolo Capital site. Do not edit `bolo-site` for NeuralFin work.
